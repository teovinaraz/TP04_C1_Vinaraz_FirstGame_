# TP04 - First Game

Pong-style game developed as part of the Programming with Video Game Engines I course.

## About the Game

A two-player Pong game set in a mining environment. Players control miners using their respective controls and compete to reach the required number of points.

The game includes:

- Two-player local gameplay
- Physics-based player and ball movement
- Increasing ball speed
- Configurable player speed and paddle size
- Configurable rounds to win
- Score and match timer
- Pause menu
- Obstacles
- Power-ups
- Object Pool system for spawned objects
- Main menu and game settings

## Controls

### Player 1
- W, A, S, D: Move up and down

### Player 2
- Up, Left, Right, Down Arrow: Move up and down

### General
- Escape: Pause the game

## Settings

The game allows the following settings to be modified:

- Player 1 speed
- Player 2 speed
- Paddle size
- Rounds to win

## Technologies

- Unity 6
- C#
- Unity 2D Physics
- Unity Input System
